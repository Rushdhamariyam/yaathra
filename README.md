# Yaathra Kerala

Yaathra Kerala is a Flask-based tourism web application that helps users explore beautiful destinations across Kerala with hotel details, travel information, and destination highlights.

## Features

- Explore famous tourist destinations in Kerala
- Hotel and stay information
- Destination details with images
- Responsive user interface
- Search and navigation system
- Flask backend with SQLite database

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
